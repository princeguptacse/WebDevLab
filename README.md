## 📖 About
This repository holds all 13 lab practicals (P01 to P13). It starts with terminal and Git basics, moves through semantic HTML and CSS foundations, and ends with modern CSS layout using Flexbox and Grid. Each practical folder contains the source code and a screenshot of the output.

## ▶️ How to Run
1. Clone the repository:
   ```bash
   git clone https://github.com/princeguptacse/WebDevLab.git
   cd WebDevLab
   ```
2. Open any practical folder (for example `P09`).
3. Double-click `index.html`, or open it with the **Live Server** extension in VS Code.
